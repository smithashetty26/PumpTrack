# ⛽ PumpTrack

PumpTrack is a Fuel Station Management and Finder web application developed using React and Firebase. It allows users to locate nearby fuel stations, check real-time fuel availability, view queue status, and navigate directly using Google Maps. The application also provides an admin dashboard for managing station information.

## Features

### User Module

- User Registration
- User Login & Logout
- Secure Firebase Authentication
- Search Fuel Stations
- View Station Details
- Check Fuel Availability
- View Queue Status
- Distance Calculation
- Nearby Station Detection
- Google Maps Navigation
- User Profile

### Admin Module

- Admin Login
- Add Fuel Station
- Update Fuel Station
- Delete Fuel Station
- Dashboard Statistics
- Export Station Data to CSV

## Installation

Clone the repository

```bash
git clone https://github.com/smithashetty26/PumpTrack.git
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm run dev
```

Build for production

```bash
npm run build
```
